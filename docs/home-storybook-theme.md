# Home storybook theme

The student homepage opts into `data-home-theme="storybook"` on its existing `#app-root`. `src/features/home/home-theme.css` is imported by `HomePage.tsx`; every visual rule is limited to that root. Existing Home/search/leaderboard controllers, module capability requests, lesson callbacks and stable IDs remain unchanged.

The skin reuses local Nunito fonts and the vocabulary decoration atlas. Cream panels have cyan double rims, rounded raised buttons and small stars. Cambridge cards retain distinct pastel colors. Actions use a pale cream/peach/orange gradient with dark brown lettering; secondary controls use ivory cream. The leaderboard uses a warm gold frame, trophy and tinted medal cards. The footer preserves the weekly quote and copyright inside a light panel above the existing illustrated garden. The classroom achievement photograph remains intact.

The warm refinement reuses `/logo.png`, the existing global bear favicon, for the navbar brand mark. Header History/logout strokes and the initial avatar have explicit readable colors. IOE and Speaking opening buttons share a 184px width, capped by their available space. The seven decorative exam icons use circular CSS crops from `/assets/lesson-cards/starter-wood-cards-v2.webp`: dog, cat, bird, monkey and rabbit, matching the Starters yard boards. This adds no generated/downloaded image assets or module behavior changes.

The later wordmark refinement replaces only the navbar's plain brand text with a transparent glossy toy wordmark: coral “Tiếng”, honey “Anh”, mint “Cô” and cyan “Diệu”, with two gold sparkles. It retains the bear and the accessible image name “Tiếng Anh Cô Diệu”. Built-in imagegen produced the master `output/imagegen/home-wordmark-v1.png`; its full prompt is `output/imagegen/home-wordmark-v1.prompt.md`. The served `/assets/branding/home-wordmark-v1.webp` retains the original 2152×731 dimensions and exact alpha, using 203,352 bytes. CSS frames the lettering without changing the image. Below 480px, account controls use a second row so the lettering stays legible. Hero copy remains native text.

The IOE/Speaking opening labels explicitly share Nunito 500, 16px and a 24px line height. Before correction, the inherited Competition font produced Inter 800 while Speaking's scoped rule produced Nunito 700. The Home-only override keeps both 184×44px buttons and their warm colors. Computed styles and reviewed screenshots match on real-component fixtures and actual localhost at 1440/390px; navigation callbacks and GET-only checks pass, and canonical build passes. Evidence: `.data/home-entry-font-verification/{baseline,browser-report}.json`; snapshot `.data/home-entry-font-before.css`.

Search and grade controls gain vocabulary-specific IDs and accessible labels. Buttons have 44px minimum targets, visible keyboard focus, readable disabled states and a gentle hover lift that respects reduced motion. Phone lesson rows wrap titles and put the action below the metadata. The soft page backdrop is fixed behind the entire document; decoration never intercepts input.
